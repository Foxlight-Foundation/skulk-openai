Chat and API

On a compatible Skulk build, owner-enabled models appear under capability models in chat and in GET /v1/models. Send their exact returned IDs to POST /v1/chat/completions.

Requests require direct owner access to that gateway. Streaming, code rendering, and mounted TTS use the normal chat path. Paired-device inference grants and distributed routing remain separate acceptance gates.
